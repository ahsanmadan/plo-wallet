# Plo Code of Conduct

Plo should be a respectful and practical space for building better personal finance tools.

## Expected Behavior

- Be respectful and constructive.
- Keep feedback focused on the work.
- Assume good intent, but clarify when something is unclear.
- Help keep discussions useful, calm, and professional.
- Respect privacy and avoid sharing personal information without permission.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without consent.
- Spam, trolling, or disruptive comments.
- Any behavior that makes collaboration unsafe or hostile.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior does not match this code of conduct.

Reports can be sent privately to the project maintainer through GitHub.

## Scope

This code applies to project spaces such as issues, pull requests, discussions, commits, and related communication channels.
