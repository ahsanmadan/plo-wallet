# Lilium 🌸

**Lilium** adalah aplikasi pencatat keuangan (*money tracker*) dan pengelola keuangan pribadi yang simpel dan elegan. Proyek ini dikembangkan secara personal untuk memudahkan pemantauan arus kas, anggaran, dan transaksi harian.

Aplikasi ini merupakan *fork* dan modifikasi dari proyek open-source [Ivy Wallet](https://github.com/Ivy-Apps/ivy-wallet), yang disesuaikan kembali dengan kebutuhan dan preferensi pribadi.

## ✨ Fitur Utama

- **Pencatatan Transaksi**: Catat pemasukan dan pengeluaran harian dengan mudah.
- **Manajemen Anggaran (Budgeting)**: Atur batas pengeluaran untuk berbagai kategori agar keuangan tetap terkontrol.
- **Statistik & Laporan**: Lihat ringkasan keuangan dalam bentuk grafik yang indah dan mudah dipahami.
- **Multikurs (Multi-currency)**: Mendukung berbagai mata uang.
- **Desain Modern**: Antarmuka pengguna (UI) yang bersih, elegan, dan mendukung Mode Gelap (Dark Mode).

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan teknologi Android modern:
- **Bahasa Pemrograman**: 100% Kotlin
- **UI Framework**: Jetpack Compose
- **Arsitektur**: Clean Architecture & MVVM
- **Database**: Room (SQLite)
- **Dependency Injection**: Dagger Hilt

## 🚀 Cara Menjalankan Aplikasi (Local Development)

1. Pastikan Anda sudah menginstal **Android Studio** versi terbaru.
2. Clone repositori ini ke komputer Anda:
   ```bash
   git clone https://github.com/ahsanmadan/Lilium.git
   ```
3. Buka proyek hasil *clone* tersebut di Android Studio.
4. Tunggu proses sinkronisasi Gradle selesai.
5. Jalankan aplikasi (Run `app`) pada Emulator atau perangkat Android asli yang terhubung.
